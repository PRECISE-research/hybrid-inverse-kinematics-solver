# Security

## Reporting

Report a security problem privately through GitHub:
[Report a vulnerability](https://github.com/PRECISE-research/hybrid-inverse-kinematics-solver/security/advisories/new),
or the **Security** tab on this repository. Private reports are visible only to
the maintainers. You need to be signed in to GitHub to open the form.

That covers problems in the tool itself, such as a setup file that makes it
crash in an exploitable way, and any concern that the deidentified example data
in `examples/` could help identify a participant. Do not open a public issue
for either, and do not include identifying information in your report.

This is research software maintained alongside other work, so responses are
best effort. Expect an initial reply within 30 days.

## Supported versions

Fixes go into `main` and the next release. Earlier releases are not patched.
